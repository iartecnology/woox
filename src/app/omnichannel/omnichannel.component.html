{{ channelTestResult['telegram']?.success ? '✅' : '❌' }} {{ channelTestResult['telegram']?.message }}
{{ showGuides['telegram'] ? '▼ Ocultar Guía de Telegram' : '▶ ¿Cómo crear tu Bot de Telegram en 1 minuto?' }}
  1. Abre tu app de Telegram y busca al usuario verificado @BotFather.
  2. Envía el comando /newbot y asígnale un nombre visible y un nombre de usuario terminado en bot (ej. MiTiendaOficialBot).
  3. Copia el HTTP API Token generado y pégalo en el campo de arriba.
  4. Haz clic en "Activar y Vincular Webhook de Telegram". ¡Tu bot quedará listo de inmediato!

⚙️ Webhook de Messenger & Instagram en Meta for Developers

{{ channelTestResult['facebook']?.success ? '✅' : '❌' }} {{ channelTestResult['facebook']?.message }}
{{ showGuides['facebook'] ? '▼ Ocultar Guía de Facebook/Instagram' : '▶ ¿Cómo configurar Messenger e Instagram Business?' }}
  1. En tu Meta App, asegúrate de añadir los productos Messenger e Instagram.
  2. Vincula tu Página de Facebook comercial y genera un Page Access Token con permisos pages_messaging e instagram_manage_messages.
  3. En la suscripción del Webhook, suscríbete a los eventos messages y messaging_postbacks.
  4. Pega el Token de Página en el campo de arriba y haz clic en Guardar Canales.
